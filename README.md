# FuturePortfolio

A Vampire Survivors-style game built in **Godot 4.6** as a school portfolio project.

> Status: early development — scene structure and UI skeleton only.

## Requirements

- [Godot 4.6](https://godotengine.org/download) (Forward+ renderer)

## Running the project

1. Open Godot and choose **Import**.
2. Select this repository's `project.godot`.
3. Press **F5** (or open `Assets/Scenes/game.tscn` and press **F6**).

No main scene is configured yet, so `game.tscn` must be selected manually.

## Project structure

```
Assets/
  Scenes/   game.tscn — root scene (Game, Main Scene, UI)
  Scripts/  GDScript files
  Sprites/  art assets
project.godot   Godot project configuration
icon.svg        project icon
```
